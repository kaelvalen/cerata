\caption{Overview of Cerata. Left: a query is routed to at most one adapter, which is
applied to the frozen base model; if no adapter is selected, the base model answers. The
answer is returned with the identifier of the adapter used. Right: a candidate adapter is
trained on a separate copy of the base model and inserted only if its divergence $D$ on
the canary prompts is at most $\kappa$; removal deletes the entry. Bottom: the store and
the log.}
